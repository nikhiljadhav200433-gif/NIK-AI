## 📌 Overview

NIK AI is an intelligent desktop AI assistant developed in Python. It helps users perform everyday tasks using AI-powered features such as weather updates, browser automation, web search, and voice/text interactions.

The project is designed with a modular architecture, making it easy to add new features and integrate additional AI capabilities.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/nikhiljadhav200433-gif/NIK-AI.git
```

### 2. Open the Project

```bash
cd NIK-AI
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

## ⚙️ Configuration

Create your own API keys and store them locally.

Example:

```json
{
    "gcp_api_key": "YOUR_GCP_API_KEY",
    "openrouter_api_key": "YOUR_OPENROUTER_API_KEY"
}
```

> **Important:** Never upload your real API keys to GitHub.
